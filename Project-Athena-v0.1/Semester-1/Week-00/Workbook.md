# Workbook

## Engineering Scenario

You join a new AI startup.

The project runs on every teammate's machine except yours.

Your mission is to make the project reproducible.

### Questions

1. What information would you gather first?
2. What assumptions are you making?
3. How would you isolate the problem?

## Tasks

- Install Python tooling
- Create a virtual environment
- Containerize the application
- Write your first regression test

## Reflection

What changed in your understanding of reproducibility?
