# Workbook

## Engineering Story

Welcome to Athena AI. By Friday you should have your first pull request merged.

## Exercises

1. List five hypotheses for why a project works on another engineer's machine but not yours.
2. Design experiments to validate each hypothesis.
3. Explain why virtual environments exist.
4. Explain why Docker exists.
5. Read the FastAPI repository and answer:
   - Where does execution begin?
   - How are routes organized?
   - Where are tests?
6. Run a small Hugging Face model locally and answer:
   - What is a checkpoint?
   - What happened between input text and prediction?

## Reflection

- What surprised you?
- What assumption was wrong?
- What would you do differently?
