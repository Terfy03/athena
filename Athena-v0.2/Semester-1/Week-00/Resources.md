# Resources

| Resource | Link | What to use |
| --- | --- | --- |
| **The Pragmatic Programmer** | [The Pragmatic Programmer, 20th Anniversary Edition](https://pragprog.com/titles/tpp20/the-pragmatic-programmer-20th-anniversary-edition/) | Read *A Pragmatic Philosophy*, *A Pragmatic Approach*, and *Basic Tools*. |
| **The Staff Engineer's Path** | [The Staff Engineer's Path](https://www.oreilly.com/library/view/the-staff-engineers/9781098118723/) | Optional. Read Chapters 1–2. |
| **MIT Missing Semester** | [MIT Missing Semester](https://missing.csail.mit.edu/) | Complete the **Shell**, **Version Control (Git)**, and **Data Wrangling** lectures. |
| **Docker in 100 Seconds (Fireship)** | [YouTube search](https://www.youtube.com/results?search_query=Docker+in+100+Seconds+Fireship) | Quick overview before the deeper lab. |
| **Docker Crash Course (TechWorld with Nana)** | [YouTube search](https://www.youtube.com/results?search_query=TechWorld+with+Nana+Docker+Crash+Course) | Focus on Images, Containers, and Dockerfiles. |
| **Pro Git** | [Pro Git](https://git-scm.com/book/en/v2) | Read Chapters 1–2. Free online. |
| **The Twelve-Factor App** | [The Twelve-Factor App](https://12factor.net/) | Read all 12 principles—they're short and influential. |
| **Google Engineering Practices** | [Google Engineering Practices](https://google.github.io/eng-practices/) | Read the Code Review and Testing sections. |
| **How To Ask Questions The Smart Way** | [How To Ask Questions The Smart Way](http://www.catb.org/~esr/faqs/smart-questions.html) | Read once; refer back whenever you're stuck. |
| **FastAPI (Code Safari)** | [FastAPI](https://github.com/fastapi/fastapi) | Explore the repository structure rather than trying to understand every file. |
